The URL is the contract — schema v1

Every input lives in the query string, in this order, and nothing else does. A sealed result is SHA-256 of the canonical string (everything after ?), so the same inputs always produce the same receipt.

Numbers are written in their shortest exact decimal form (0.1, not 0.10); the parser accepts either. Method: two-proportion z-test, equal arms, no continuity correction — R's power.prop.test, the same convention as the reference calculator on forwarddigital.org/tools.

One relation, two unknowns. What can I detect with the traffic I have? solves the same power.prop.test for the lift instead of the n; the solve for toggle navigates there, carrying baseline, variants, tails, alpha and power verbatim and restating the computed total as that page's traffic × days. Each page keeps its own URL, its own schema and its own seal — a receipt is a receipt for one question.
