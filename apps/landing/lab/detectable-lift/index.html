Every input lives in the query string, in this order, and nothing else does. A sealed result is SHA-256 of the canonical string (everything after ?), so the same inputs always produce the same receipt.

Numbers are written in their shortest exact decimal form (0.1, not 0.10); the parser accepts either. Visitors per variant is ⌈traffic × days / variants⌉. Method: the smallest positive relative lift for which a two-proportion z-test (equal arms, no continuity correction — R's power.prop.test solving for p2) reaches the stated power at that per-arm n; found by bisection to 1e-12 on the lift. Same convention as sample size, run backwards.
