# Projections v0 — shadows the log can cast, by functional stage

Same event log; each view = fold + selection predicate. Rules inherited from live
sessions: relational ink only for live structure; discharged state on nodes;
provenance always visible; anything scoreable is private-by-default.

## Capture
- **Intake tray** — dumps/imports not yet schematized; amnesty queue. List, not graph.
  *Residue age = health signal, not backlog* (F7).
- **Metis panel** — unschematized `note.said`, searchable; resurfaced by similarity
  at admission ("you mentioned the testimonial band in March").

## Planning (built)
- **The map** — live obligations, cascade layout. Selection: open nodes + structural edges.
- **The docket** — time projection: maturation dates, review schedules, overdue
  revisits, gated bets awaiting their arbitrating question. Calendar/timeline. This
  is where ADR-style never-revisited decisions get nagged.

## Refinement / admission
- **Customs dossier** — one solution's paperwork as a document: problem attach,
  grounds w/ provenance tiers, screens open/closed, rivals + pre-written arbitration
  rules, silver-bullet flag. Card, not graph.
- **Genealogy thread** — single-path ancestry on demand: goal → problem → evidence →
  solution → bet → verdict → spawned children. One vertical thread at a time — the
  focus-mode answer to the edge-density correction (evidence flows drawn only when asked).

## In-flight
- **Cockpit** — per-bet: locked commitment read-only, amendment timeline
  (ASRS-postured, disclosure-positive), guardrail monitors, peek discipline.

## Resolution
- **The diff (P3)** — as-planned vs as-reported, two columns, one glance.
  The COMPare-hours-to-one-click move; doubles as the share/export artifact.

## Knowledge / calibration
- **Calibration mirror** — expected-vs-actual scatter, Brier trend, per-category bias
  ("ask-design effects overestimated ~2×"), shrinkage-aware (F3). Private by construction.
- **The graveyard** — detonated problems, pruned branches, bets *not* run, with
  estimated traffic/weeks saved. Makes the tool's cheapest wins visible — the
  practitioner's answer to the audience problem (F2).
- **Surrogate validity board** — metric→construct correspondence across resolved
  bets: did conversion wins cash out in the construct later? (CAST projection.)
- **Ledger** — sortable bet table w/ tags, validity, record-quality grade
  (notebook-weight principle). The NextAfter-style element navigation.

Cheap to add, cheap to kill — projections are disposable; only the log is forever.
